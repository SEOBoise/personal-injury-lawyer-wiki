# Personal Injury Lawyer Wiki

Static source for <https://personalinjurylawyer.wiki/>.

## Public files

- `index.html` — the concise homepage reference and connected JSON-LD graph
- `resources/index.html` — the 32-source research directory
- `history/index.html` — the truthful published revision record
- `assets/` — shared CSS, local JavaScript and favicon
- `charts/` — retained research figures from the original long-form edition
- `robots.txt` and `sitemap.xml` — crawl metadata
The site uses clean public routes `/`, `/resources/`, and `/history/`. No public page URL uses an `.html` extension.

Production uses the GitHub Pages `main` branch as its origin, with DNS, TLS, proxying, and HTTP-to-HTTPS redirects managed in Cloudflare.

Sources were checked September 28, 2026. The article is general legal information and does not establish representation or predict an outcome.
