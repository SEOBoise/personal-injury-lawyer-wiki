# Personal Injury Lawyer Wiki

Static source for <https://personalinjurylawyer.wiki/>.

## Public files

- `index.html` — the homepage article and connected JSON-LD graph
- `assets/` — local JavaScript and favicon
- `charts/` — the three article charts
- `robots.txt` and `sitemap.xml` — crawl metadata
The site uses the clean public route `/`. No public page URL uses an `.html` extension.

Production uses the GitHub Pages `main` branch as its origin, with DNS, TLS, proxying, and HTTP-to-HTTPS redirects managed in Cloudflare.

Sources were checked September 28, 2026. The article is general legal information and does not establish representation or predict an outcome.
